One flat base, stacked upward. Keep every slice the same and the solid is a prism; shrink each slice towards a point and it is a pyramid. The whole difference is one number in the formula, and you can watch it happen.

Live model. Switch between prism and pyramid at the top left, choose a base, then drag the solid to turn it. Open full screen

Notes on this model

What changes, and what does not

The base never moves and the height never changes when you switch. What changes is the slice. A prism repeats the base exactly: same shape, same size, congruent at every level. A pyramid repeats it smaller and smaller until, at the apex, there is nothing left. That is why only the prism has a uniform cross-section.

Try this

Switch modes in the middle of the build and watch the same stack close to a point. Then set the base to circle: the pyramid becomes a cone, the prism a cylinder.

Press Lay it down. The solid is unchanged, but the base now faces sideways and the height runs along the axis. Height is always measured perpendicular to the base, never along a sloping face.

The two rules

prism: V = A × h

pyramid: V = ⅓ × A × h

Same base, same height, one third of the volume. The bar in the measurements card marks the third, so you can see where the pyramid stops.

Slices changes how many steps you draw, never the volume: thinner slices, same solid.

Where the one third comes from

It is not a coincidence and it is not a different formula: it is what is left when the slices shrink. Take a cube and join one corner to the three far faces. The cube falls apart into three identical pyramids, each with the same base and the same height as the cube’s own ⅓ share. Three fit, so one is a third. The same argument works for any prism, however odd its base.

Three questions to ask the class
  1. The prism and the pyramid on screen share a base and a height. Which measurements are equal, and which are not?
  2. Is a cone a pyramid? Is a cylinder a prism? Say which word is doing the work in each answer.
  3. Sketch a solid whose slices get bigger as they rise. What would its volume be, compared with the prism that wraps it?
