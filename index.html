What the chapter asks of you 學習重點

By the end you should be able to

  • Name points, lines, line segments, angles and polygons correctly and unambiguously.
  • Read and write the symbols: ∠ABC, △ABC, AB // CD, AB ⊥ CD, AB = 4 cm.
  • Classify angles, triangles and polygons using the correct vocabulary.
  • Use the angle sum of a triangle, 180°, and angles on a straight line, 180°, to find unknowns.
  • Tell polyhedra from non-polyhedra, and describe cross-sections of solids.
  • Construct parallel lines, perpendicular lines, circles and triangles with the correct tools.

How to use a plate

  1. Read the key idea. The ruled box gives the definition in one sentence.
  2. Study the diagram. Every label matters; the exam marks the labels.
  3. Work the example yourself before you press “Show solution”.
  4. Do the “Let’s check”. It is taken from the lesson worksheet.
  5. Read the red rule. That is where marks are lost.
