Points, Lines & Surfaces

點、線與面 — 幾何學的起點

Learning objectives

  1. Understand the ideas of a point, a line, a line segment and a surface (plane).
  2. Know the difference between a straight line and a line segment.
  3. Name and write these objects with correct notation.
  4. Measure the length of a line segment and write the answer with units.

1Everything starts with a point 點

Geometry is the study of shapes and space. In geometry we do not draw a real object — we draw a model of it. A point, a line and a plane are the three “undefined” objects that every other shape is built from, so we describe them instead of defining them.

Point

A point tells you where something is. It has position but no size — no length, no width, no thickness.

Point A

  • We draw it as a small dot: •
  • We name it with a CAPITAL letter: A, B, P, Q…
  • In real life: the tip of a pencil, a corner of a room, a star in the sky.
Never do this

Writing a or p (small letter) for a point. Small letters are kept for lines, lengths and angles.

Surface (plane)

A surface or plane is a flat surface with no thickness that extends in all directions without ending.

  • A plane has no edges and no corners — what you draw is only a piece of it.
  • A flat shape drawn on a plane is called a plane figure (平面圖形).
  • In real life: the top of a desk, a whiteboard, the surface of calm water.

2Line, Line Segment 直線、線段

These two look similar on paper, but they are different objects. The difference is how many endpoints they have — and therefore whether they have a length.

Straight line L 直線L

Line segment PQ 線段PQ

Key point — the one sentence to remember

A line segment (say PQ) is a part of a line which has two endpoints (say P and Q) and a fixed length (say 4 cm).
We can simply write PQ = 4 cm.

A line has no endpoints, so it has no length — you can never write L = 4 cm for a line.

3Measuring a line segment 量度線段

Length is measured with a ruler. The unit is usually the centimetre (cm) or the millimetre (mm), and 1 cm = 10 mm.

How to measure correctly

  1. Put the 0 mark exactly on one endpoint.
  2. Keep the ruler along the segment (not tilted).
  3. Read the mark at the other endpoint — look straight down, not from the side.
  4. Write the answer with a unit: 5 cm, not just 5.

Converting units

1 cm = 10 mm  ·  1 m = 100 cm

4 cm= 40 mm
7.5 cm= 75 mm
120 mm= 12 cm
2 m= 200 cm

4Worked examples 例題

Example 1Naming line segments

In the figure, A, B, C and D lie on a straight line in that order, with AB = 3 cm, BC = 2 cm and CD = 3 cm.

(a) Name the line segment which has the same length as AB.
(b) Find the length of AD.

  1. CD is 3 cm long, and AB is also 3 cm. So CD has the same length as AB.
  2. AD = AB + BC + CD = 3 + 2 + 3 = 8 cm

(a) CD    (b) AD = 8 cm

Note: AC = 5 cm and BD = 5 cm, so AC and BD are also equal in length. Both are correct answers to a question worded “name a segment with the same length as …”.

Example 2Line or segment?

Decide whether each statement is true or false.

(a) AB = 6 cm can describe a straight line.
(b) A line segment has two endpoints.
(c) A ray has no endpoint.

(a) False. A line has no endpoints, so it has no fixed length. Only a segment has a length.

(b) True. That is exactly what makes it a segment.

(c) False. A ray has one endpoint and then goes on forever.

5Let's check 課堂練習

Check yourself

Refer to the figure. P, Q, R and S lie on a straight line, PQ = 4 cm, QR = 4 cm and RS = 2 cm.

  1. Name the line segment(s) which has / have the same length as PQ.
  2. Name the line segment which is the longest.
  3. Find PS.
  4. Is PR = QS? Explain briefly.
  1. QR (also 4 cm).
  2. PS = 10 cm, so it is the longest.
  3. PS = 4 + 4 + 2 = 10 cm
  4. No. PR = 4 + 4 = 8 cm but QS = 4 + 2 = 6 cm, so PR ≠ QS.

!Common mistakes 常見錯誤

✗ WrongAB = 4 cm where AB is a line
✓ RightAB = 4 cm (a segment has a length)
A line never ends, so it has no length. Only a line segment can be measured.
✗ WrongPoint a, point b
✓ RightPoint A, point B
Points use CAPITAL letters. Small letters are used for lines and for angles.
✗ WrongAC is a segment in the figure above
✓ RightAC is a segment, but it is not drawn — it is made of AB + BC
Any two points on a line form a segment, even if no line is drawn between them. Read the question: does it ask for segments shown or all possible segments?
✗ WrongAnswer: 5
✓ RightAnswer: 5 cm
A length without a unit is incomplete — and in a test it can cost a mark.
✗ WrongMeasuring from the end of the ruler
✓ RightMeasuring from the 0 mark
Many rulers have a small blank margin before the 0 mark. Starting at the edge gives a wrong length.
